# AuraUtils v1.0.0 — Release Notes

Release date: 2026-05-20

## Highlights
- A collection of player utility commands focused on quality-of-life: homes, warps, back, TPA, TPA Here, safe random teleport, flight, god mode, no-fall, and no-hunger, with a central `/menu` GUI.
- `/aura reload` reloads configuration, and permissions are fine-grained with an `aura.admin` umbrella permission for operators.
- Simple persistence keeps players' toggles and homes between sessions.

## Full feature list
- Homes: `/sethome`, `/home`, `/delhome` (supports multiple named homes)
- Warps: `/setwarp`, `/warp`, `/delwarp`
- Teleport requests: `/tpa`, `/tpahere`, `/tpaccept`, `/tpadeny` (configurable timeout)
- Toggles: `/fly`, `/god`, `/nofall`, `/nohunger`
- Utility: `/back`, `/menu`, `/rtp`, `/aura reload`, `/aura`

## Configuration
- See `src/main/resources/config.yml` for configurable options (TPA timeout, teleport countdown, home limits, safe RTP radius, minimum RTP distance, attempts, cooldown, and chat prefix).

## Notes
- This release reflects the current utility commands and toggles shipped in the codebase.

## Installation
1. Build the plugin with Maven: `mvn clean package` (Java 21+).
2. Drop `target/AuraUtils-1.0.0.jar` into your server `plugins/` folder.
3. Restart the server and edit `plugins/AuraUtils/config.yml` if desired.

## Known considerations
- Permissions default to safe values (many basics default to `true`; powerful toggles default to `op`). Review `plugin.yml` before deploying on production servers.
- The plugin targets Spigot/Paper 1.21+; compatibility with older server builds is not guaranteed.

## Artifact
