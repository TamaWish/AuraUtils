# AuraUtils v1.0.0 — Release Notes

**Release date:** 2026-05-23

## Highlights

- All-in-one player utilities: homes, warps, back, TPA, TPA Here, **async-safe** RTP, spawn, heal/feed, toggles, and `/menu` GUI.
- **One JAR** for Spigot and Paper — runtime detection for async chunks, movement-aware countdowns, and client locale.
- **MiniMessage** locales in `messages/*.yml` with gradients, hover, and click-to-cancel teleports.
- **`features:` toggles** in `config.yml` to disable command groups without removing the plugin.
- `/aura reload` reloads gameplay config and all message files.

## Utility menu

`/menu` opens the main GUI (warps, homes, TPA, spawn, heal, feed, back, refresh). Warp and home lists support pagination (45 entries per page).

## Messages & localization

- Default: `plugins/AuraUtils/messages/en.yml`
- Sample: `messages/es.yml`
- Config: `messages.default-locale`, `messages.fallback-locale`, `messages.use-client-locale`
- Prefix: `meta.prefix` in each locale file (MiniMessage)

See [README — Messages & localization](../README.md#messages--localization).

## Configuration

Primary file: `plugins/AuraUtils/config.yml`

- TPA timeout, global teleport countdown, RTP radius/attempts/cooldown
- **Paper RTP:** `generate-chunks`, `async-urgent`, `max-pending-chunk-loads`
- **Spigot RTP:** `only-loaded-chunks: true` + pre-generated worlds
- **Teleports:** `teleport.async-chunk-load`, `teleport.sync-chunk-fallback`
- Home limits, server keep inventory, **feature toggles**
- Locale defaults (chat text is in `messages/*.yml`)

Platform tuning: [README — Random teleport](../README.md#random-teleport-async-safe).

## ResourceWorldResetter

Works with [ResourceWorldResetter](https://github.com/TamaWish/ResourceWorldResetter): RWR for resets and `/rwr tp`; AuraUtils for `/rtp`, `/back`, homes, warps, TPA. `/setspawn` coordinates persist in `server-spawns.yml`.

## Installation

1. **Java 25+** required to build and run.
2. Build — see [docs/BUILD.md](../docs/BUILD.md):

   ```powershell
   .\.maven\apache-maven-3.9.16\bin\mvn.cmd clean package
   ```

3. Copy **`target/AuraUtils-1.0.0.jar`** to `plugins/` (this is the shaded artifact; do not use `original-AuraUtils-1.0.0.jar`).
4. **Restart** the server.
5. Edit `config.yml` and `messages/en.yml` as needed.

### Deploying safely

Build with Maven only. IDE-exported JARs compiled while the workspace has errors can fail at enable with `Unresolved compilation problems` in `MenuManager` or other classes.

## Known considerations

- Review `plugin.yml` defaults before production (many basics are `true`; powerful toggles are `op`).
- Paper strongly recommended for async RTP and rich chat components.
- On Spigot, RTP searches loaded chunks only when `rtp.only-loaded-chunks: true`.
- Rich hover/click chat works best on Paper; Spigot may show legacy fallback text.
