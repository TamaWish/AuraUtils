# AuraUtils v1.0.0 — Release Notes

Release date: 2026-05-20 (artifact not yet published to GitHub)

## Highlights

- Player utilities in one plugin: homes, warps, back, TPA, TPA Here, **async-safe** random teleport, flight, god mode, no-fall, no-hunger, and a `/menu` GUI.
- **One JAR for Spigot and Paper** — detects Paper at runtime for async chunk loads, movement-aware teleport countdowns, and optional client locale.
- **MiniMessage locales** — operator-editable `messages/en.yml` (and more) with gradients, hover text, and click-to-cancel teleports.
- `/aura reload` reloads gameplay config and message files; granular permissions with `aura.admin` for operators.

## Full feature list

- **Homes:** `/sethome`, `/home`, `/delhome` (multiple named homes, GUI, limits)
- **Warps:** `/setwarp`, `/warp`, `/delwarp` (per-warp permissions)
- **Teleport requests:** `/tpa`, `/tpahere`, `/tpaccept`, `/tpadeny` (configurable timeout)
- **Toggles:** `/fly`, `/god`, `/nofall`, `/nohunger` (optional targets with `.others` permissions)
- **Utility:** `/back`, `/menu`, `/rtp`, `/auracanceltp`, `/setspawn`, `/keepinventory`
- **Admin / info:** `/aura`, `/aura reload`, `/aura locale <code|clear>`

## Messages & localization

- Default strings: `plugins/AuraUtils/messages/en.yml`
- Sample translation: `messages/es.yml` (extend or replace for your server)
- Config: `messages.default-locale`, `messages.fallback-locale`, `messages.use-client-locale`
- Prefix and colors: `meta.prefix` in each locale file (MiniMessage syntax)

See [README.md](../README.md#messages--localization) for examples and locale resolution order.

## Configuration

Primary file: `plugins/AuraUtils/config.yml`

- TPA timeout, global teleport countdown
- RTP radius, min distance, attempts, per-tick batching, countdown, cooldown
- **Async RTP (Paper):** `generate-chunks`, `async-urgent`, `max-pending-chunk-loads`; leave `only-loaded-chunks` unset/false
- **Conservative RTP (Spigot):** set `only-loaded-chunks: true` and pre-generate terrain for best results
- **Teleports:** `teleport.async-chunk-load` (Paper), `teleport.sync-chunk-fallback` (Spigot)
- Home limits, server-wide keep inventory
- Message locale defaults (not chat text — that is in `messages/*.yml`)

See [README.md — Random teleport (async-safe)](../README.md#random-teleport-async-safe) for platform-specific tuning.

## ResourceWorldResetter

Works alongside [ResourceWorldResetter](https://github.com/TamaWish/ResourceWorldResetter): use RWR for world resets and `/rwr tp`; use AuraUtils for `/rtp`, `/back`, homes, warps, and TPA. `/setspawn` coordinates persist when worlds are recreated.

## Installation

1. Build: `mvn clean package` (**Java 25+**).
2. Place `target/AuraUtils-1.0.0-shaded.jar` (or `AuraUtils-1.0.0.jar`) in `plugins/`.
3. Restart the server.
4. Edit `plugins/AuraUtils/config.yml` and `plugins/AuraUtils/messages/en.yml` as needed.

## Known considerations

- Review `plugin.yml` permission defaults before production (many basics are `true`; powerful toggles are `op`).
- Targets **Spigot/Paper 1.21+**; Paper strongly recommended for async RTP, client locale, and teleport movement detection.
- On Spigot, `/rtp` only searches loaded chunks when `rtp.only-loaded-chunks: true`; use world pre-generation for large radii.
- Rich chat (hover/click) works best on Paper; Spigot receives legacy-formatted fallback text.
